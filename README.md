A fairly basic project to introduce me to C++
I will create a digital version of Rock Paper Scissors were the players can use the command line to input a value which will correspond to Rock, Paper or Scissors.
I will also implement a pseudorandom number generator to allow for games against the computer.
Goals:
- Learn to code in C++
- Learn how to use C++ Input Streams
- Apply basic testing
- Use proper commenting
- Practice version control
Steps:
- Add enum to store Rock, Paper or Scissors
- Add a class to handle player input
- Add a class to handle the game itself and computer actions
- Add a testing class before full implementation
